## Clay Enrichment Prompts

### Prompt 1: Endpoint Count Estimation
```
Review {{company_name}}'s employee count ({{employee_count}}) and industry ({{industry}}).

Estimate their endpoint count using these rules:
- Office-based companies: 1.2 endpoints per employee
- Manufacturing: 0.8 endpoints per employee
- Retail with POS: 1.5 endpoints per employee
- Healthcare: 1.3 endpoints per employee

Return estimated endpoint count and confidence level (high/medium/low).
```

### Prompt 2: Tech Stack Validation
```
Review {{company_name}}'s technology stack data.

Check if they use any of these:
- ITSM: ServiceNow, BMC Helix
- DEX: Nexthink, Lakeside SysTrack, ControlUp
- UEM: Microsoft Intune, Jamf, Ivanti, Tanium
- Virtual Desktop: Azure Virtual Desktop, Windows 365, Nerdio

Return: technologies found, confidence level, and whether they qualify as "mature ITSM stack."
```

### Prompt 3: Hiring Signal Detection
```
Review {{company_name}}'s current job postings.

Count open positions for:
- Help Desk Technician
- IT Support Specialist
- L1/L2 Support
- IT Operations Manager
- Digital Workplace Lead
- EUC Engineer

Return: total count, role breakdown, and signal strength (high/medium/low).
If 5+ support roles, mark as HIGH signal.
```

### Prompt 4: Leadership Change Detection
```
Review recent news and announcements for {{company_name}}.

Look for:
- New CIO hired (last 6 months)
- New VP/Director of IT Operations (last 6 months)
- New VP/Director of Digital Workplace/EUC (last 6 months)
- New Chief AI Officer hired
- AI transformation initiative announced

Return: findings, recency, and whether this creates buying urgency.
```

### Prompt 5: Trigger Event Detection
```
Review recent news for {{company_name}}.

Look for:
- Major IT outage or system failure
- Public complaints about IT service quality
- SLA breach mentions
- Security incident with slow response time
- DEX or ITSM platform migration/renewal mentioned
- Upcoming compliance audit

Return: event type, recency, severity, and whether it signals immediate buying intent.
```
