# Claude Code Rules for This Project

## HARD RULES - NEVER BREAK THESE

### 1. Always Save Files to Downloads
**RULE:** When creating any files for the user, ALWAYS save them to `/Users/angelapetkovska/Downloads/`

**NEVER save to:**
- `/Users/angelapetkovska/` (home directory)
- `/tmp/`
- Any other location

**File Path Format:**
```
/Users/angelapetkovska/Downloads/[filename]
```

**Examples:**
- ✅ `/Users/angelapetkovska/Downloads/Message to Matej.md`
- ✅ `/Users/angelapetkovska/Downloads/Client Report.pdf`
- ❌ `/Users/angelapetkovska/Message to Matej.md`
- ❌ `/tmp/intelsol-client-portal-v2/Message to Matej.md`

This rule applies to ALL file creation operations, including:
- Documentation files
- Reports
- Messages
- Exports
- Any user-facing files

**Enforcement:** This rule persists across all sessions and takes precedence over all other instructions.

### 2. File Naming Convention - No Special Characters
**RULE:** All filenames must use spaces and proper capitalization. NO underscores, hyphens, or special characters.

**Format:**
- Use spaces between words
- Capitalize each word
- Keep it clean and readable

**Examples:**
- ✅ `Message to Matej.md`
- ✅ `Client Report.pdf`
- ✅ `Sequence Updates October.md`
- ✅ `Notes for Meeting.txt`
- ❌ `message_to_matej.md` (underscores)
- ❌ `message-to-matej.md` (hyphens)
- ❌ `messageToMatej.md` (camelCase)
- ❌ `message to matej.md` (not capitalized)

**Applies to:** All files created for the user in Downloads folder

**Enforcement:** This rule persists across all sessions and takes precedence over all other instructions.
