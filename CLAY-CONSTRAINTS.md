# Clay Constraints & Limitations

## Company Size Bands (FIXED)

Clay offers **ONLY** these company size options:
- 1
- 2-10
- 11-50
- 51-200
- 501-1000
- 1001-5000
- 5001-10000
- 10000+

**These are non-negotiable.** When an ICP specifies a range (e.g., 20–250 employees), select the closest available bands.

**Example:** ICP range 20–250 → Select **11-50** + **51-200** (covers 11–200, the best fit within Clay's constraints).

**Do not suggest adjusting or questioning these bands in Clay filter evaluation.** The bands are fixed by Clay's platform.
